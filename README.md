# Student Marks Analysis using Python

This is a simple Python project that demonstrates basic data analysis and visualization.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Features
- Calculates average, highest, and lowest marks
- Visualizes student performance using a bar chart

## How to Run
1. Install Python
2. Install required libraries:
   pip install pandas matplotlib
3. Run the script:
   python student_marks_analysis.py

## Output
- Console output showing statistics
- Bar chart displaying student marks
